## 本次修复

原 512×512 像素头像的非透明范围为 `(21,21)` 至 `(490,490)`，四边约 21 像素透明留白，蓝底本身还预先做过大圆角。圆形展示时透明区域会露出底色，容易形成白圈。

本版直接从项目原 `brand-logo.svg` 导出，保持标识路径、位置、渐变与双色层次，移除背景圆角和透明留白。蓝色背景延伸至四边及四角，由平台裁切形状。

没有替换项目现有 `logo.png`，没有自动上传微信。截图中的白边与现有透明边相吻合；无法据此确认微信后台当前正在使用的原上传文件。

各尺寸 PNG 都保留相同构图，按微信后台当前提示选择尺寸与裁切范围。文件体积和像素检查见 `validation.json`。
