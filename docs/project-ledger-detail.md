# 项目账套台账明细

项目划分合同后，台账按当前企业、项目中的已生效合同以及已确认的对账流水实时生成，无需额外建表或手工补录历史单据。移出合同后，其合同金额和关联流水不再显示在该项目台账中。

按往来公司分组，同一公司的采购、销售分开列示。每组按业务日期、确认时间和记录 ID 排序，包含合同、销售单、退货单、转款单、发票及作废冲销记录。每笔流水保留单据编号和所属合同编号。已失效、已删除或不属于当前企业的合同不计入明细。

表格列顺序沿用提供的模板：日期、名称、合同金额、金额、转款、未转款、已开发票、未开发票。

- 合同金额单独列示，不计入实际业务金额。
- 金额包含已确认销售单及退货单。退货金额为负数。
- 未转款为累计金额减累计转款。
- 未开发票为累计转款减累计已开发票，沿用模板口径。
- 作废冲销在原列以反向金额列示，不重复计数。

数据通过结算模块 `ReconciliationAccountOperations.projectLedgerEntries` 读取，兼容合并部署和服务拆分部署。项目查询、Excel 导出和结算流水读取均要求当前企业管理员权限；流水查询同时限制企业和合同 ID。

接口：

- `GET /api/project-ledgers/{id}/ledger`：项目台账标题、日期、分组、明细和合计。
- `GET /api/project-ledgers/{id}/ledger/workbook-data`：沿用小程序文件下载协议，返回 Excel 文件名称、类型及 Base64 内容。

Excel 保留公司分组、八列表头和合计行，日期和金额使用原生单元格类型，余额与合计使用公式。小程序打开文件时启用菜单，支持保存和分享。
