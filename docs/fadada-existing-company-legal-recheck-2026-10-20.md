# 已认证企业重新核验法人：接口核查（2026-10-20）

## 核查结论

本轮查阅法大大当前 5.1、5.0 官方接口目录、认证授权说明、帮助中心及项目使用的 Java SDK `5.8.7.0428.3`。**未找到能够明确支持“已认证且已授权企业，由当前法人本人重新核验，核验后返回可绑定当前申请人与企业的结果，无需原超管批准、无需重置超管、无需新增收费”的公开可接入路径。**这不是法大大绝对没有此能力的结论；未公开能力、合同中已有的特殊能力及实际计费资格仍需厂商确认。

因此，本轮没有把 `legalRepFace` 当成已认证企业的强制复核开关，没有调用未获文档支持的业务接口，也没有新增付费能力。满帅目前不能依靠本轮研究实现上述全自动法人入驻。

云域已对应用授权与满帅本人的法人身份证据是两个独立事实。云域已有授权应直接复用，不应要求武英龙重复批准同一授权；尚缺的本人证据也不能由已有企业授权代替。

## 本地实现与实际状态

- 之前的已有授权复用、所属企业默认 `clientCorpId` 兼容和前端待核验状态保留，详见[云域入驻核查](./yunyu-owner-onboarding-audit-2026-10-20.md)。这些代码已通过原定向验证，但未发布。
- 本轮仅补充研究记录，没有新增自动法人核验代码，没有改变现有身份放行条件，没有改变法大大企业绑定、超管或授权。
- 没有新增付费服务、发起收费核验或发起企业找回／重新认证。
- 本人证据不足时仍保留待核验，平台线下人工支持仍是现有后备路径；目前没有可直接点击批准的生产人工审核闭环，不能承诺该路径已自动完成。
- 本轮没有代码变更，因此未重复运行此前已通过的 155 项后端、373 项前端及 25 项配置测试。
